## 2024-07-26 - Do not apply aria-live to interactive elements
**Learning:** Adding `aria-live` directly to interactive, focusable elements like `<button>` is an accessibility anti-pattern. Because focus remains on the button when clicked, screen readers often announce text changes automatically, and `aria-live` can cause inconsistent behavior (like reading the change twice or conflicting role announcements).
**Action:** When implementing temporary UI feedback (like "Copied!"), apply `aria-live="polite"` to a non-interactive wrapper container (e.g., `<div class="copy-field" aria-live="polite">`) rather than the `<button>` itself.
